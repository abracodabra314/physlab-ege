# Физическая лаборатория ЕГЭ · задача №10

Интерактивный настольный тренажёр для подготовки к **задаче №10 ЕГЭ по профильной
математике** (текстовые задачи на движение, работу, наполнение и смешивание).
Каждая модель — это живая физическая сцена: объекты можно двигать мышью,
параметры менять на лету, запускать и перематывать анимацию, а правая панель
параллельно показывает **полный математический вывод ответа** — так, как задача
решается в тетради.

Все вычисления выполняются локально, без обращения к сети и без сторонних
физических движков: математика написана вручную и покрыта тестами.

## Возможности

- **Шесть интерактивных моделей** типовых сюжетов задачи №10:
  1. **Два движущихся автомобиля** — встречное движение, обгон, задержка старта;
     закон движения `s₁ = s₁₀ + v₁·t`, момент встречи из `s₁(t) = s₂(t)`.
  2. **Движение теплоходов** — скорость по и против течения
     `v = v_соб ± v_теч`, время рейса `t = L / v`, задержка отправления.
  3. **Резервуар с водой** — краны наполнения и слива,
     `V(t) = V₀ + (q₁ + q₂ − q₃)·t`, момент «бак полон» / «бак пуст».
  4. **Колодец: камень и эхо** — свободное падение `h = g·t²/2` и возврат звука
     `T = t₁ + t₂`, есть и обратная задача (глубина по времени эха).
  5. **Совместная работа механизмов** — `A = (p₁ + p₂)·t`, раздельный и
     совместный этапы, три механизма.
  6. **Смешивание растворов** — `C = (V₁C₁ + V₂C₂) / (V₁ + V₂)`,
     масса вещества `m = V·C`, поэтапная перекачка насосом.
- **Перетаскиваемые объекты сцены**: координаты автомобилей, пристани, уровень
  воды, глубина колодца, положение шестерён, объёмы растворов. Drag меняет
  параметр модели, а модель мгновенно пересчитывает ответ.
- **Панель исходных параметров**: числовые поля, ползунки, переключатели и
  выпадающие списки с валидацией (недопустимые состояния не возникают —
  значение либо корректируется, либо сценка помечается некорректной).
- **Панель вычислений**: условие → обозначения → уравнение → решение → ответ,
  дроби, индексы и формулы отрисованы средствами Qt (без LaTeX и без сети).
  Панель можно скрыть горячей клавишей во время эксперимента.
- **Пульт эксперимента**: запуск, пауза, продолжить, сброс, пошаговый кадр и
  выбор скорости анимации; перемотка модельного времени ползунком.
- **Полноэкранный режим и адаптация схемы под любое разрешение** окна.
- Интерфейс полностью на русском языке.

## Структура проекта

```
phisics_sim/
├── CMakeLists.txt          сборка: библиотека lab_lib + приложение physlab + тесты
├── assets/
│   └── icons/lab_icon.svg  эскиз иконки (в приложении иконка рисуется вектором)
├── src/
│   ├── main.cpp            точка входа, ключ --shots
│   ├── ModelFactory.*      реестр «модель + сцена» (новое модель — одна строка)
│   ├── core/               Simulation (базовый класс), ModelTypes — чистая математика
│   ├── models/             6 моделей: MotionModel, BoatModel, TankModel,
│   │                       WellModel, WorkModel, MixtureModel
│   ├── scenes/             QGraphics-сцены, DragHandleItem, примитивы и стиль
│   ├── ui/                 LabWindow, ParamPanel, ReadoutPanel, DerivationPanel,
│   │                       ExperimentController, LabView, ShotsMode
│   └── utils/              MathText — рендер математической разметки в rich-text
└── tests/                  67 модульных тестов ядра (GoogleTest)
```

Архитектурное правило: **математика полностью отделена от отрисовки**. Состояние
сцены в любой момент вычисляется из параметров как функция времени
`stateAt(t)` — поэтому анимация корректно перематывается в обе стороны, а
параметры можно менять прямо во время движения.

## Сборка

Нужны Qt 6 (Widgets) и CMake. GoogleTest либо уже установлен, либо будет
получен автоматически через `FetchContent` (нужен интернет при первой
конфигурации; иначе сконфигурируйте с `-DLAB_BUILD_TESTS=OFF`).

### macOS (Homebrew)

```bash
brew install qt googletest
cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt
cmake --build build -j
./build/physlab
```

### Linux (APT)

```bash
sudo apt install build-essential cmake qt6-base-dev libgtest-dev
cmake -S . -B build
cmake --build build -j
./build/physlab
```

### Windows

Установите Visual Studio 2022 (компонент «Desktop development with C++»),
CMake и Qt 6 (через Qt Online Installer). Затем из «Developer Command Prompt»:

```bat
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:\Qt\6.xx\msvc2022_64
cmake --build build --config Release
build\Release\physlab.exe
```

## Тесты

Тесты проверяют только математическое ядро (без окна): известные «учебные»
ответы задач, границы и недопустимые параметры, форматирование формул.

```bash
cmake -S . -B build -DLAB_BUILD_TESTS=ON
cmake --build build -j
ctest --test-dir build --output-on-failure
```

## Управление

| Действие | Как |
|---|---|
| Выбрать модель | карточка в каталоге |
| Открыть установку | клик по карточке модели |
| Запуск / пауза / продолжить | кнопки пульта, `Пробел` (переключение) |
| Только старт с нуля | `S` |
| Шаг на один кадр | `→` или кнопка «Шаг» |
| Сброс | `R` или кнопка «Сброс» |
| Перематка времени | ползунок «t» в панели текущих величин |
| Скорость анимации | раскрывающийся список 0,1× … 8× |
| Изменить параметр | поля левой панели или перетаскивание объектов сцены |
| Скрыть/показать вычисления | `D` или меню «Настройки» |
| Во весь экран / в окно | `F` или кнопка в верхней панели |
| К списку моделей | `Esc` или «← К моделям» |

Замечание: эксперимент автоматически останавливается ровно в момент ключевого
события задачи (встреча, полный бак, эхо, готовая работа, готовая смесь),
когда оно достижимо при текущих параметрах.

## Служебный режим снимков

```bash
./build/physlab --shots /tmp/labshots
```

Открывает каждую модель и сохраняет в указанную папку по три кадра
(начало / середина / конец эксперимента) — удобно для быстрой визуальной
проверки сборки.

## Добавление новой модели

1. Производный класс от `core/Simulation`: параметры (`ParamSpec`),
   `stateAt(t)`, `validate()`, `derivation()`, `readouts()`, `handles()`.
2. Сцена-потомок `scenes/LabScene`: отрисовка в `paintScheme()` и, при
   необходимости, отображение ручек drag в модельные величины.
3. Одна строка-фабрика в `src/ModelFactory.cpp`.
4. Тесты новой математики в `tests/` и регистрация в `tests/CMakeLists.txt`.
