# Физическая лаборатория ЕГЭ

Интерактивный настольный тренажёр для подготовки к **задаче №10 ЕГЭ по профильной
математике** (текстовые задачи на движение, работу, наполнение и смешивание)
и к физическим экспериментам: пятнадцать живых моделей — от двух автомобилей
и резервуаров с водой до пружин, звука, адиабаты, радиоактивного распада и
конструктора электрической цепи. Каждая модель — это живая физическая сцена:
объекты можно двигать мышью, параметры менять на лету, запускать и перематывать
анимацию, а правая панель параллельно показывает **полный математический
вывод ответа** — так, как задача решается в тетради.

Все вычисления выполняются локально, без обращения к сети и без сторонних
физических движков: математика написана вручную и покрыта тестами.

## Возможности

- **Шесть интерактивных моделей** типовых сюжетов задачи №10:
  1. **Два движущихся автомобиля** — встречное движение, обгон, задержка старта;
     закон движения `x₁ = x₁₀ + v₁·max(0, t − t₁)`, момент встречи из `x₁(t) = x₂(t)`.
     Дорога с разметкой, координатная ось с отметками км, размерная линия расстояния.
  2. **Движение теплоходов** — скорость по и против течения
     `v_зем = v ± u`, время рейса `t = L / |v_зем|`, задержка отправления.
     Векторы «по воде», «течение» и «по берегу» в одном масштабе; подсветка
     пристани в момент прибытия.
  3. **Резервуар с водой** — краны наполнения и слива с включением/выключением,
     `V(t) = V₀ + (Σqᵢ)·t` с ограничением `0 ≤ V ≤ Vmax`, уровень `h = V / A`.
  4. **Колодец: камень и эхо** — свободное падение `h − h₀ = g·t²/2` и возврат звука
     `T = t₁ + t₂`; точку отпуска камня можно двигать по вертикали; обратная задача
     (глубина по времени эха) решается точно, квадратное уравнение относительно `√h`.
  5. **Совместная работа механизмов** — единая модель `A(t) = Σ pᵢ·max(0, t − tᵢ)`:
      у каждого механизма своё время включения, свой статус (выключен / работает /
      завершил) и личный вклад; производственная линия с конвейером и продукцией,
      пропорциональной выполненной доле.
  6. **Смешивание растворов** — `C = (V₁C₁ + V₂C₂) / (V₁ + V₂)`,
     масса вещества `m = V·C`; краны линий открываются по очереди или одновременно,
     закрытый кран исключает раствор из смеси.
- **Девять физических экспериментов**: полёт тела, брошенного горизонтально и
  под углом, пружина на столе и пружина в поле тяжести, «корабль Галилея» с
  края уступа, эхо гудка судна, адиабатное сжатие газа, радиоактивный распад,
  деление бактерий и **конструктор электрической цепи** — сборка схемы на
  клетчатом листе с расчётом методом узловых потенциалов. В этих моделях
  графики строятся по рассчитанным данным, переходные процессы интегрируются
  численно, теоретическая кривая отличается от дискретного счёта, а векторы
  имеют обозначения и включаются по категориям отдельно.
- **Вид «чертёж в тетради»**: все сцены рисуются как рисунок на уроке физики —
  белая бумага в синюю клетку, тонкие чернильные контуры тел, штриховка опор.
  На самом рисунке нет числовых значений: тела и размерные линии подписаны
  обозначениями (`s`, `h`, `t₁ = h/c`), количества остались на боковых панелях,
  шкале времени и графиках (для этого есть `labels::stripValues`).
- **Перетаскиваемые объекты сцены**: координаты автомобилей, пристани и теплоходы,
  уровень и высота бака, краны, уровень воды и точка отпуска камня в колодце,
  производительности станков, объёмы растворов. Любое касание объекта
  **останавливает время**, drag меняет параметр модели, а модель мгновенно
  пересчитывает ответ; при изменении параметров сцена заново подгоняет масштаб,
  чтобы объекты не выходили за границы.
- **Общая система векторов** (`scenes/VectorArrows`): единые цвета и обозначения
  для всех сцен — скорость `v`, ускорение `a`, сила тяжести `mg`, реакция `N`,
  трение `F_тр`, натяжение `T`, поток. Рядом со стрелкой только символ, без чисел;
  длина пропорциональна величине. Силы показываются лишь там, где модель их
  считает, и в динамических моделях (пружина, маятник, бросок, «корабль
  Галилея», поршень) нарисованы всегда — полный набор действующих сил.
  Скорости и ускорения включаются/выключаются и масштабируются независимо:
  «Настройки → Векторы на сценах» (сохраняется между запусками).
- **Ось времени внизу каждой сцены**: по ней бежит точка состояния, есть отметка
  ключевого события задачи; клик или перетаскивание по оси перематывает
  модельное время (эксперимент при этом останавливается).
- **Панель исходных параметров**: числовые поля, ползунки, переключатели и
  выпадающие списки с валидацией (недопустимые состояния не возникают —
  значение либо корректируется, либо сценка помечается некорректной).
- **Панель вычислений**: условие → обозначения → уравнение → решение → ответ,
  дроби, индексы и формулы отрисованы средствами Qt (без LaTeX и без сети).
  Панель можно скрыть горячей клавишей во время эксперимента.
- **Пульт эксперимента**: запуск, пауза, продолжить, сброс, пошаговый кадр и
  выбор скорости анимации; перемотка модельного времени ползунком.
- **Полноэкранный режим и адаптация схемы под любое разрешение** окна.
- Интерфейс полностью на русском языке.

## Технологии

| Компонент | Реализация |
|---|---|
| Язык | C++20 |

| Тесты | GoogleTest (ctest-интеграция) |

## Структура проекта

```
phisics_sim/
├── CMakeLists.txt          сборка: библиотека lab_lib + приложение physlab + тесты
├── assets/
│   └── icons/lab_icon.svg  эскиз иконки (в приложении иконка рисуется вектором)
├── src/
│   ├── main.cpp            точка входа, ключ --shots
│   ├── ModelFactory.*      реестр «модель + сцена» (новое модель — одна строка)
│   ├── core/               Simulation (базовый класс), ModelTypes — чистая математика
│   ├── models/             15 моделей: MotionModel, BoatModel, TankModel,
│   │                       WellModel, WorkModel, MixtureModel, ProjectileModel,
│   │                       SpringModel, HorizonModel, SoundModel, GasModel,
│   │                       DecayModel, BacteriaModel, CircuitModel
│   ├── circuit/            CircuitNet (топология схемы) и MnaSolver (ОМ)
│   ├── scenes/             QGraphics-сцены, DragHandleItem, VectorArrows (общие
│   │                       векторы), SchemePrimitives, стиль
│   ├── ui/                 LabWindow, ParamPanel, ReadoutPanel, DerivationPanel,
│   │                       ExperimentController, LabView, ShotsMode
│   └── utils/              MathText — рендер математической разметки в rich-text
└── tests/                  575 модульных тестов ядра и сцен (GoogleTest)
```

Архитектурное правило: **математика полностью отделена от отрисовки**. Состояние
сцены в любой момент вычисляется из параметров как функция времени
`stateAt(t)` — поэтому анимация корректно перематывается в обе стороны, а
параметры можно менять прямо во время движения.

## Сборка

Нужны Qt 6 (Widgets) и CMake. GoogleTest либо уже установлен, либо будет
получен автоматически через `FetchContent` (нужен интернет при первой
конфигурации; иначе сконфигурируйте с `-DLAB_BUILD_TESTS=OFF`).

### macOS (Homebrew)

```bash
brew install qt googletest
cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt
cmake --build build -j
./build/physlab
```

### Linux (APT)

```bash
sudo apt install build-essential cmake qt6-base-dev libgtest-dev
cmake -S . -B build
cmake --build build -j
./build/physlab
```

### Windows

Установите Visual Studio 2022 (компонент «Desktop development with C++»),
CMake и Qt 6 (через Qt Online Installer). Затем из «Developer Command Prompt»:

```bat
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:\Qt\6.xx\msvc2022_64
cmake --build build --config Release
build\Release\physlab.exe
```

## Тесты

Тесты проверяют только математическое ядро (без окна): известные «учебные»
ответы задач, границы и недопустимые параметры, форматирование формул.

```bash
cmake -S . -B build -DLAB_BUILD_TESTS=ON
cmake --build build -j
ctest --test-dir build --output-on-failure
```

## Управление

| Действие | Как |
|---|---|
| Выбрать модель | карточка в каталоге |
| Открыть установку | клик по карточке модели |
| Запуск / пауза / продолжить | кнопки пульта, `Пробел` (переключение) |
| Только старт с нуля | `S` |
| Шаг на один кадр | `→` или кнопка «Шаг» |
| Сброс | `R` или кнопка «Сброс» |
| Перематка времени | ползунок «t» в панели текущих величин или нижняя ось времени сцены (клик / перетаскивание точки) |
| Скорость анимации | раскрывающийся список 0,1× … 8× |
| Изменить параметр | поля левой панели или перетаскивание объектов сцены (время при этом останавливается) |
| Векторы на сценах | «Настройки → Векторы на сценах»: скорости / ускорения / силы, масштаб стрелок |
| Собрать цепь (модель «Цепь») | деталь из палитры — клик по клетке, повторный клик — поворот на 90°, правый клик — убрать; провод — два клика по клеммам (или по двум клеткам) |
| Скрыть/показать вычисления | `D` или меню «Настройки» |
| Во весь экран / в окно | `F` или кнопка в верхней панели |
| К списку моделей | `Esc` или «← К моделям» |

Замечание: эксперимент автоматически останавливается ровно в момент ключевого
события задачи (встреча, полный бак, эхо, готовая работа, готовая смесь),
когда оно достижимо при текущих параметрах.

## Служебный режим снимков

```bash
./build/physlab --shots /tmp/labshots
```

Открывает каждую модель и сохраняет в указанную папку по три кадра
(начало / середина / конец эксперимента) — удобно для быстрой визуальной
проверки сборки.

4. Тесты новой математики в `tests/` и регистрация в `tests/CMakeLists.txt`.
